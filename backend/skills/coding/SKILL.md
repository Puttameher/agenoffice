# Coding Skill

**Category**: Software Engineering  
**Agent**: Alex (Coding Agent)

## Description
Full-stack coding skill for writing, debugging, testing, and optimizing code across multiple programming languages. Executes code in a secure Python sandbox.

## Capabilities
- Python script writing and execution via `python_runner`
- Debugging and error analysis
- Code review and optimization
- Algorithm design and implementation
- Test generation (unit tests, integration tests)
- Script automation

## Usage
Assign tasks that require:
- Writing Python scripts or functions
- Debugging broken code
- Building CLI tools or automation scripts
- Data processing and transformation
- Code refactoring and optimization

## Example Tasks
- "Write a Python script to parse CSV and compute statistics"
- "Debug this function — it returns the wrong output"
- "Create a web scraper for product prices"
- "Implement a binary search tree in Python"

## Tools Required
- `python_runner`
