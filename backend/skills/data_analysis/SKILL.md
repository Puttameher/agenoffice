# Data Analysis Skill

**Category**: Quantitative Analysis  
**Agent**: Rio (Analysis Agent)

## Description
Quantitative data analysis skill for financial modeling, statistical computation, chart generation, and data-driven insights using the calculator and Python tools.

## Capabilities
- Financial calculations (compound interest, ROI, NPV, IRR) via `calculator`
- Statistical analysis (mean, median, variance, regression)
- Data visualization (chart data extraction for frontend rendering)
- KPI tracking and performance benchmarking
- Spreadsheet-style computation

## Usage
Assign tasks that require:
- Financial modeling and forecasting
- Investment return calculations
- Statistical summaries and hypothesis testing
- KPI dashboards and metric analysis
- Ratio analysis (P/E, debt-to-equity, etc.)

## Example Tasks
- "Calculate compound interest on $10,000 at 8% over 20 years"
- "Analyze this sales dataset and find the top 3 trends"
- "What is the NPV of this investment opportunity?"
- "Build a portfolio allocation model with risk-adjusted returns"

## Tools Required
- `calculator`
- `python_runner` (optional, for complex computations)
