# PDF & Document Skill

**Category**: Document Processing  
**Agent**: Mika (Content Agent) / Jordan (Manager)

## Description
Document reading, extraction, and summarization skill for processing PDF files, reports, contracts, and structured text documents using the file_reader tool.

## Capabilities
- PDF reading and text extraction via `file_reader`
- Document summarization (executive summaries)
- Key clause and entity extraction from contracts
- Report parsing and structured data extraction
- Multi-document comparison

## Usage
Assign tasks that require:
- Summarizing uploaded PDF documents
- Extracting specific sections from reports
- Analyzing contract terms and conditions
- Processing research papers or technical documentation
- Comparing multiple documents side-by-side

## Example Tasks
- "Summarize this PDF annual report in 5 bullet points"
- "Extract all financial figures from this contract"
- "What are the key risks mentioned in this document?"
- "Compare these two product specification sheets"

## Tools Required
- `file_reader`
