# Dual-Loop Memory

Dual-Loop Memory provides continuous cognitive evolution across tasks.

- **Loop 1 (Episodic)**: Key-value agent working memories, active branch notes, and scratchpad preferences.
- **Loop 2 (Organizational)**: Distills lessons (`taskSummary`, `strategy`, `whatWorked`, `whatFailed`, `lesson`) stored in SQLite and indexed for similarity search.
- **Human Knowledge Vault**: Markdown notes with YAML frontmatter, backlinks, and tags living in the user's Obsidian [[Office Architecture]].
