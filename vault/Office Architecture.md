# Office Architecture

The AgenOffice platform is an autonomous agentic workplace built on top of the [[Cordis Microkernel]].

## Core Principles
- **Modularity**: Every capability is a standalone Cordis plugin with reversible lifecycle.
- **Dual-Loop Memory**: Seamlessly ties short-term scratchpads to long-term organizational wisdom. See [[Dual-Loop Memory]].
- **Multi-Agent Roster**: Five permanent employees collaborate across specialized desks. See [[Agent Roster]].
- **Zero-Install Tooling**: Fast, native automation engines including [[Playwright Automation]].
